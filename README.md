# Tanish Sanchaniya - Personal Developer Portfolio

> "Learning, building, and creating with technology."

A personal, professional, job-focused developer portfolio website created for **Tanish Sanchaniya**, a Computer Science student (BCA 5th Semester Completed) and aspiring Full-Stack Developer based in Surat, Gujarat, India.

---

## 📌 Project Overview

This portfolio is built using **pure HTML5, CSS3, and Vanilla JavaScript** with clean code architecture, smooth scroll animations, accessible components, and responsive mobile-first design.

## 🚀 How to Run Locally

1. Clone or download this repository.
2. Open `index.html` in any modern browser or serve via Python / HTTP server:
   ```bash
   python -m http.server 8080
   ```
3. Open `http://localhost:8080` in your web browser.
